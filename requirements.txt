# Dependencias de Bones & Paws

# Se usan rangos en vez de versiones exactas (==) a proposito: una version
# clavada puede no tener instalador ("wheel") para la version de Python del
# equipo donde se instale, y ahi pip falla al compilar. Con "mayor o igual,
# menor que la siguiente version mayor" se instala siempre la ultima version
# compatible, sin riesgo de cambios que rompan el codigo.
#
# Instalacion:  python instalar.py     (recomendado)
#         o:    pip install -r requirements.txt
